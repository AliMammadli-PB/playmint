# Curated game gifts

Twenty replacements are now managed by separate editorial curator profiles; original authors and source licences remain credited in each game's page and runtime. The rejected `opensource-*` catalogue is retired. The manifest pins upstream revisions and per-game notices. Rail Rush 3D and Miso Garden 3D are original Playmint games gifted to aliska, using MIT-licensed Three.js.

Uploads use the normal extractor and real VirusTotal approval. Identical collection runtimes share one completed analysis only after repacking and checking every SHA-256. Review and covers use the actual browser runtime, including the opaque-origin sandbox and phone input. Device saves expose a bounded game namespace through the parent bridge; account/session storage is inaccessible.

Existing VPS SWF games use pinned, self-hosted Ruffle 0.7.0. The operator explicitly requested public embedding; this authorization is recorded separately from verified redistribution rights and does not invent a licence or transfer original copyright. A combined scan is reused only for byte-identical runtime members. Legacy keyboard games retain desktop compatibility metadata.
